# Password Generator Using Python

## Overview
Password Generator Using Python is a simple and customizable tool to create secure passwords. The script allows users to specify the number of letters, symbols, and numbers in their password, ensuring strong and unique passwords every time.

---

## Features
- **Customizable Input**: Specify the number of letters, symbols, and numbers for the password.
- **Randomized Order**: Characters are shuffled to enhance security.
- **Simple and Efficient**: Lightweight script for quick password generation.

---

## How to Use
1. Run the Python script.
2. Provide the number of:
   - Letters
   - Symbols
   - Numbers
3. The script will generate and display a secure, randomized password.

---

## Example Usage
### Input
```plaintext
How many letters would you like in your password?
5
How many symbols would you like?
3
How many numbers would you like?
2
```

### Output
```plaintext
['A', 'k', 'z', 'B', 'j', '&', '!', '%', '3', '7']
['j', 'B', 'k', 'A', '&', '%', '7', 'z', '!', '3']
Your password is: jBkA&%7z!3
```
